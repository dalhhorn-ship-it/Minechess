# Minechess v0.1: iPad check and kid playtest

For the owner. Two parts: a 20 minute check on your own, then short play sessions with each child. Afterwards, send the notes (or just tell Claude what you saw) and they become the v0.2 priorities.

## Part A. Your 20 minute iPad check (alone)

Open the Cloudflare link in Safari on the iPad the kids will use. Tick each line or note what went wrong.

| # | Do this | Expect | OK? |
|---|---|---|---|
| A1 | Hold the iPad upright (portrait) | A picture asks you to turn the iPad | |
| A2 | Turn it sideways | Start screen: MINECHESS title, three creatures | |
| A3 | Tap Wobble | Board appears, your light pieces at the bottom, the gold glow shows it is your turn | |

If anything freezes: note what you tapped just before, then reload the page.

## Part B. Kid sessions

Plan two short sessions per child (10 to 20 minutes) on different days. Sit next to them but **don't help** unless they are stuck for more than about 30 seconds; being stuck is exactly what we want to learn about.

**Younger child (5):** suggest Wobble first, then Clucky.
**Older child (9):** let them pick. Expect them to try Copper Bot.

Watch for:

| Question | Younger child (5) | Older child (9) |
|---|---|---|
| Could they start a game without help? | | |
| Did they understand whose turn it was? | | |
| Did they notice the creature's move (and captured pieces)? | | |
| Did they use tap, drag, or both? Any mis-taps? | | |
| Did they use oops? Did they understand it? | | |
| What made them laugh or react to the creature? | | |
| Did they win? How did it end (checkmate, white flag, draw)? | | |
| Did anything frustrate them or make them want to stop? | | |
| Did they ask to play again, or come back to it later on their own? | | |
| Favourite creature, and why? | | |
